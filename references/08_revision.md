# Stage 8 · Revision

1. Split every report into numbered points. Classify: new experiment · new analysis · text · disagree.
2. One plan table: point · action · owner · time · changes to which figure. Agree it with the authors before any work.
3. Reply point by point: thank once, answer first, quote the changed text with its location, show the new panel. Disagree with evidence, never with tone.
4. Keep a diff of the manuscript; mark changes as the journal asks.
