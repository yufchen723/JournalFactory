# Changelog
- 0.4.0 (2026-11-18): first public release. `cell-skills/`, a Cell skill pack built on the nature-skills pattern with Cell's own rules (cell-figure with matplotlib and ggplot2 styles, templates, gates and a dependency-free PDF/TIFF audit; cell-writing, cell-statistics, cell-reviewer, cell-response, cell-data, cell-citation, cell-shared). Cell's author pages read on cell.com; `journals/cell.json` is `official`. New command `jf cell`.
- 0.3.0: BioCartoon built in (`bin/jf-cartoon`, `jf cartoon`), local catalogue only.
- 0.2.0: built-in studio for text and figures (`studio/`, `jf studio`, `jf paper init`) with a Journal tab and journal checks.
- 0.1.0: nine stages with guides; 13 journal profiles with verification level; `jf` (journals, compare, fit, count, check-figure, field, paper, doctor); PubMed and Europe PMC helpers; field-learning stage; bundled reference skills.
