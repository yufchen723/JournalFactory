# Source basis for `cell-statistics`

*Adapted in structure from nature-skills (nature-statistics/references/source-basis.md), Apache-2.0; Cell rules from cell-shared/journal-formats/cell.md.*

This file keeps the skill honest about where each statement comes from.

## Source hierarchy

1. **The user's own material**: decision letter, reviewer comments, statistical analysis plan, the editor's instructions. These override everything below.
2. **Cell rules**: only what is recorded in `../../cell-shared/journal-formats/cell.md` (read on cell.com on 2026-11-18).
3. **Study-type reporting guidelines** (for example for trials or animal studies): use only when the study type clearly applies or the user asks. Their use by Cell is not specified in cell.md — check cell.com.
4. **Craft guidance**: general statistical practice. Useful, but not journal policy.

## What cell.md says about statistics

These are the only statistical statements that may be called a Cell rule.

| Statement | Where |
|---|---|
| Legends, main and supplemental, state the statistical test(s) and the p value each asterisk stands for, e.g. "*p < 0.05, **p < 0.01 by Student's t test (A, F, and H) or by two-way ANOVA (K and L)" | cell.md §4 |
| Legends state the number of biological and technical replicates for each result | cell.md §4 |
| Legends state what every measure and error bar is, e.g. "Data are represented as mean ± SEM" | cell.md §4 |
| Legends name related supplemental items: "See also Figure S1" | cell.md §4 |
| Recommended: plot individual data points in addition to mean ± error | cell.md §5 (image integrity list) |
| Compare only data that belong together (same experiment) | cell.md §5 |
| STAR Methods has a section "Quantification and statistical analysis" (heading taken from the author guide, not re-read on 2026-11-18; confirm in the PDF) | cell.md §8 |
| STAR Methods format is required at revision and for acceptance, not at first submission | cell.md §1, §8 |
| Methods never go in the supplement | cell.md §7 |
| AI used in the research itself is reported in STAR Methods | cell.md §3 |

## What cell.md does not say

Treat every item below as **craft guidance**. If the user needs the official position: "not specified in cell.md — check cell.com".

- Exact p values versus thresholds.
- One-sided versus two-sided tests; reporting of test statistics and degrees of freedom.
- Effect sizes and confidence intervals.
- Which multiple-testing correction to use.
- Sample-size calculation, randomization, blinding, inclusion and exclusion criteria. These are widely expected in a methods section, but cell.md does not list them.
- What "Quantification and statistical analysis" must contain. The STAR Methods author guide PDF was not read.
- Any reporting checklist or form about statistics.
- Source-data files for figures.

## Not read

cell.md lists these as unverified: the STAR Methods author guide PDF, the journal-policies page, the final file requirements PDF. Open the page before relying on any detail from them.

## Rule against cross-journal import

Nature's statistical checklist (exact n, two-sided tests, test statistic with degrees of freedom, reporting summary) is Nature's. Do not present it as Cell's. Where the same practice is good craft, give it as craft guidance.
