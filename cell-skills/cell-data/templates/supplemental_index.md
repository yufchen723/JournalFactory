# Supplemental information index — template

> **Cell rule (cell.md §7):** the manuscript carries a "Supplemental information" index with Document S1 first.
> Items are named Figure S1, Table S1, Data S1, Methods S1, Video S1 (never "Supplementary …"). Supplemental
> figure titles end "related to Figure N". Tables longer than 3 pages are Excel files. Methods never go in the
> supplement. Document S1: A4/Letter, ≤ 50 MB, Arial 10 pt, no title, authors or page numbers. No file above
> 500 MB. Recommended ≤ 20 supplemental figures.
>
> The exact sentence form of the index is not given in cell.md; the lines below are a pattern. Check a recent
> Cell article or cell.com. Replace every [bracket]; delete this note and the working table.

## Checks

- [ ] Document S1 is listed first.
- [ ] Every item is cited in the main text or STAR Methods.
- [ ] Every supplemental figure title says "related to Figure N", with current figure numbers.
- [ ] Every related main legend says "See also Figure S#".
- [ ] No methods in any supplemental file.
- [ ] Tables over 3 pages are Excel files; others are inside Document S1.
- [ ] Document S1 ≤ 50 MB; no file above 500 MB; data and code in non-proprietary formats.
- [ ] Supplemental figures ≤ 20 (recommended). Short article: ≤ 4 supplemental figures, ≤ 8 items (cell.md §2).
- [ ] Supplement-only references are in the supplemental list only, numbered independently.
