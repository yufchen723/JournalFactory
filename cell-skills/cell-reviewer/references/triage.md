# Editor triage: what could stop a paper before review

**Inference (not Cell policy).** cell.md contains no text on how Cell editors triage submissions, on desk-return criteria, or on presubmission inquiries. For the official process: not specified in cell.md — check cell.com. This file applies the selection criteria in cell.md §2 as an editor reading quickly might.

## 1. What an editor reads first — inference

Title → Summary → cover letter → Highlights (if supplied) → figure titles → last paragraph of the Introduction → first and last figures. A triage read does not reach the supplement.

So the advance must be visible in those places.

## 2. Risk table

Rate each row: present / partly / absent. Any "present" in group A is a serious risk.

### A. Advance and fit (criterion: cell.md §2)

| Risk | How to detect it in the draft |
|---|---|
| No conceptual advance stated | The Summary describes what was done; no sentence says what is now understood |
| Advance is incremental | The central claim extends a known mechanism to one more context |
| Narrow interest | Only one subfield is named or implied; the Introduction needs specialist background to motivate the question |
| Descriptive for a research article | Results are a catalogue; no hypothesis is tested |
| Resource without proof of principle or insight | Method runs, or dataset exists, but no finding demonstrates its value (cell.md §2 wording for Resource) |
| Wrong article type | A method/dataset paper submitted as a research article, or the reverse |
| Central claim is correlative but worded as mechanism | Causal verbs in title or Summary; no perturbation in the figures |
| Scooped or overlapping | A close published paper or preprint is not addressed (verify; do not assume) |

### B. Evidence visible at a glance

| Risk | How to detect it |
|---|---|
| Single system, single cohort | All figures draw on one model or one patient set |
| No orthogonal validation | Every claim rests on one data type |
| Key control missing in the main figures | The specificity control is in the supplement or absent |
| Statistics look unsafe | n in cells or spots; bars without points |

### C. Presentation

| Risk | Rule or guidance |
|---|---|
| Title is long, jargon-heavy or method-led | **Cell rule** (cell.md §3): about 10–12 words, ≤ 145 characters with spaces, no jargon or uncommon abbreviations, conveys the broad conceptual significance |
| Summary over 150 words, with citations or abbreviations | **Cell rule** (cell.md §3) |
| "Novel", "first" | **Cell rule** (cell.md §3): discouraged |
| Subheadings name analyses | **Cell rule** (cell.md §3): state the finding |
| More than 7 display items or over 7,000 words | **Cell rule** (cell.md §2) |
| Hard-to-read figures | craft guidance; first submission is free format (cell.md §1), but a triage reader still has to see the result |
| Cover letter repeats the Summary | craft guidance: use it to state the advance, the audience and the closest prior work |

Format alone is unlikely to be the reason, since first submissions are free format (cell.md §1). Format problems matter when they hide the advance.

### D. Integrity and compliance

| Risk | Rule |
|---|---|
| Image manipulation concerns | **Cell rule** (cell.md §5): whole-image adjustments only; spliced lanes marked; figures are screened |
| AI-generated or AI-altered data images | **Cell rule** (cell.md §5): not allowed |
| No data or code route | **Cell rule** (cell.md §3): Resource availability is a required section at revision; an editor may still ask early (inference) |
| Missing ethics statements for human or animal work | not specified in cell.md — check cell.com |

## 3. Triage output

```text
Editor triage read (inference, not Cell policy)

One-sentence advance as an editor would restate it:
Most likely reason to send for review:
Most likely reason to return without review:

Risks
| Group | Risk | Rating | Where seen | Lowest-cost fix |
|---|---|---|---|---|

Fix before submission: [up to three]
Could be argued in the cover letter: [items]
Consider a different article type or journal if: [condition]
```

## 4. Lowest-cost fixes — craft guidance

| Problem | Fix that needs no new data |
|---|---|
| Advance not visible | Rewrite title, Summary and last Introduction paragraph around one finding |
| Mechanism wording on correlative data | Step down the wording ladder (see `attack-surface.md` §2); own it in "Limitations of the study" |
| Method paper posed as biology | Switch to Resource; lead with the capability and its proof of principle |
| Narrow framing | Open the Introduction with the general question; name the second community that benefits |
| Key control buried | Move it into the main figure |
| Overlap with prior work | Add a direct, fair comparison paragraph; cite it |

If the honest one-sentence advance does not meet the criterion in cell.md §2 after these fixes, say so plainly. That is the most useful output of a triage read.
