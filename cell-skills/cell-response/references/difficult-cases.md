# Difficult cases

*Adapted in structure from nature-skills (nature-response/references/difficult-cases.md), Apache-2.0; Cell rules from cell-shared/journal-formats/cell.md.*

Craft guidance (not a journal rule). cell.md records no procedure for any of these cases. Where the journal's process matters (extensions, appeals, reviewer visibility): not specified in cell.md — check cell.com or ask the editor.

## 1. The requested experiment is not feasible

1. Name the concrete constraint (material no longer exists; the model takes longer than the revision period; the assay does not exist for this system).
2. Identify the question behind the request.
3. Offer the strongest substitute that answers the same question: orthogonal assay, existing dataset, reanalysis.
4. Narrow the claim to what the substitute supports.
5. Add the limit to "Limitations of the study".
6. Tell the editor in the cover letter. For an S1 item, ask the editor **before** resubmitting whether the substitute is acceptable.

Do not write "beyond the scope" for an experiment that tests the central claim.

## 2. Two reviewers conflict

- Decide once, in the revision plan, on the scientific merits and the editor's signals.
- Answer each reviewer on the merits of their own point. Do not cite the other reviewer as the reason.
- Look for a change that serves both (shorten the main text and move the detail to STAR Methods or a supplemental figure).
- Flag the conflict and the decision in the cover letter.

## 3. Two reviewers ask the same thing

- One action. Two complete answers, each in that reviewer's section, each with the location.
- Do not write "see response to R1.2".

## 4. The reviewer is factually wrong

- Check first. Reviewers are right more often than authors expect.
- If wrong: state the fact with evidence, without the word "wrong". Find what in the manuscript invited the misreading and fix it.
- If the error is about the literature, cite the verified source (`cell-citation`).

## 5. The reviewer asks for a different paper

- Category `SCOPE`. Check the editor's letter: was the request endorsed?
- If not endorsed: explain what the present paper claims, what the request would add, and why it is a separate study. Add the open question to the Discussion.
- If endorsed: it is S1. Plan it or discuss alternatives with the editor.

## 6. "Descriptive", "incremental", "not a conceptual advance"

- This is about the criterion in cell.md §2, not about one figure.
- Options: (a) add the experiment that tests the main hypothesis; (b) reframe title, Summary, Introduction end and subheadings around the finding; (c) change article type (for example to Resource) with the editor's agreement.
- Answer in the response with what changed, not with an argument that the paper was already an advance.

## 7. Request to cite specific papers

- Cite when relevant, after verifying each paper and what it shows.
- If not relevant, say why in one sentence and cite what is.
- If a cited paper overlaps with the claims, add a fair comparison.

## 8. Statistics dispute

- Hand the item to `cell-statistics`.
- If the reviewer's method is better, adopt it and report what changed, including results that weakened.
- If both are defensible, show both; keep the more conservative one in the main figure.
- Update the legend and "Quantification and statistical analysis" together (**Cell rule** for legend content, cell.md §4).

## 9. A result changed or did not replicate

- Say so plainly, in the response and in the manuscript.
- Remove or weaken the claim everywhere: title, Summary, Highlights, eTOC blurb, graphical abstract.
- Tell the editor in the cover letter. Concealed changes are found.

## 10. Image or data integrity question

- S1. Involve the corresponding author immediately.
- Provide the original, unprocessed data. **Cell rule** (cell.md §5): originals are available on request; adjustments apply to the whole image; spliced lanes are marked and stated in the legend; AI tools may not create or alter research images.
- Correct the figure and explain exactly what happened. Do not minimise.

## 11. The revision breaks a limit

- New panels and text push past 7,000 words or 7 display items (**Cell rule**, cell.md §2).
- Move secondary panels to supplemental figures ("related to Figure N"); move method detail from legends and Results to STAR Methods, which is not counted (cell.md §2).
- Do not move methods into the supplement (**Cell rule**, cell.md §7).
- Say in the response where displaced content went.

## 12. Not enough time

- Ask the editor for an extension early, with a date and the reason (which experiment, what stage). The extension procedure is not specified in cell.md.
- Do not submit a response that promises the experiment later.

## 13. Hostile or unconstructive report

- Extract the answerable content; answer it normally.
- Ignore tone. Do not mirror it.
- If a point is unanswerable as phrased, say what was done about the underlying issue.
- Raise concerns about the review itself only in the cover letter, factually.

## 14. Appeal-like cases (rejection)

- Not the default. First run an honest read with `cell-reviewer`: is the rejection about fit to cell.md §2 (hard to appeal) or about a factual error or a fixable gap (possible)?
- Appeals need new information: data that answer the central objection, or a demonstrable error in a report.
- The appeal procedure is not specified in cell.md — check cell.com.
- Often the better route is a new submission elsewhere using the reviews as a plan.
