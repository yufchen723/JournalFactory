# Cell (Cell Press) — research article format, from the journal's own pages

Read on cell.com on **2026-11-18** (in a browser; the site refuses automated fetches).
Every number in the Cell skills comes from this file. If a number is not here, it is not an
official Cell rule: say so, and do not import a Nature rule in its place.

## 1. Which stage each rule applies to

| Stage | What applies |
|---|---|
| Initial submission | Free format. Figures in any format, size, resolution; may be embedded in the text; keep files small (1–2 MB). Formatting rules below "do not need to be met". STAR Methods format not required. [FIG, REVISE, STAR] |
| Revision | Manuscript components and order (section 3); STAR Methods format **required**; cover letter + point-by-point response. [REVISE] |
| Final (production) files | Figure production rules (section 5), highlights + eTOC blurb, graphical abstract, supplemental files, forms. [FINAL, FIG] |

Do not fail a first-submission draft on production-only rules. Report them as "needed later".

Revision package [REVISE, FINAL]: (1) a **new cover letter** "briefly summarizing how the revised
manuscript addresses the reviewer and editor comments"; it is "confidential to the editor";
(2) a letter with **detailed point-by-point responses** to the reviewer and editor comments.
Revised papers inactive for more than 1 year are withdrawn automatically. Whether a marked-up
manuscript is required is not stated on these pages.

## 2. Article types and length [TYPES]

| Type | Main text | Display items | Notes |
|---|---|---|---|
| Research article | **under 7,000 words**, counting main figure legends; not counting STAR Methods text, supplemental item legends, references | **no more than 7** figures and/or tables | "conceptual advances of unusual significance regarding a biological question of wide interest" |
| Resource | same as research article | same | technical advance with proof of principle, or a major database with "provocative new biological insights" |
| Theory | same | same | testable predictions required |
| Short article | ≤ 4,000 words (counts title, authors, affiliations, summary, legends) | ≤ 4 | ≤ 4 supplemental figures, ≤ 8 supplemental items in total |
| Matters Arising | same as research article | same | no revision round |

## 3. Manuscript components, in order [REVISE]

Title · Author list · Affiliations and footnotes · Contact information · Summary · Keywords ·
Introduction · Results · Discussion (with a "Limitations of the study" subsection) ·
Resource availability · Acknowledgments · Author contributions · Declaration of interests ·
Declaration of generative AI and AI-assisted technologies (only if used) ·
Supplemental information titles and legends · Figure titles and legends · Tables · STAR Methods · References.

| Part | Rule |
|---|---|
| Title | about 10–12 words, **≤ 145 characters with spaces**; no jargon or uncommon abbreviations; conveys the broad conceptual significance |
| Summary | one paragraph, **≤ 150 words**; background/purpose, principal results with approach/model system and main conclusions, broader significance; no citations; no non-standard abbreviations |
| Keywords | up to **10**, comma separated |
| Introduction | succinct; pertinent background; ends with a brief statement of what was achieved; **no subheadings** |
| Results | subsections with short, informative subheadings that state the finding ("Factor X requires factor Y to function in process Z", not "Analysis of factors X and Y using approach Q"); use similar wording in figure titles |
| Discussion | implications and context, not a repeat of Results; includes **Limitations of the study**, specific to the paper |
| Resource availability | required; three subsections: Lead contact · Materials availability · Data and code availability |
| Author contributions | required; CRediT taxonomy encouraged, initials |
| Declaration of interests | required; must match the form; "The authors declare no competing interests." if none |
| Generative AI declaration | required when generative AI was used in preparing the manuscript (not for grammar/spelling/reference tools); AI used in the research itself is reported in STAR Methods |
| Lead contact | exactly one; must be a corresponding author |
| Novelty words | Cell discourages "novel" and "first": "overused … difficult to verify" |
| Style | US spelling; abbreviations minimal, defined at first use, avoided in the title; gene symbols italic, proteins roman; no footnotes outside the author list and tables |
| Final format | editable, preferably Word; LaTeX also needs a PDF |

## 4. Figure titles, legends and tables [REVISE]

- Each figure: a brief **title** for the whole figure (no panel citations), then the legend describing each panel.
- Re-use the Results subheadings as figure titles.
- Legends (main and supplemental) must state:
  - the statistical test(s), and the p value each asterisk stands for, e.g. "*p < 0.05, **p < 0.01 by Student's t test (A, F, and H) or by two-way ANOVA (K and L)";
  - the number of biological and technical replicates for each result;
  - what every measure and error bar is, e.g. "Data are represented as mean ± SEM";
  - every scale bar (in the image or in the legend);
  - related supplemental items: "See also Figure S1".
- All figures cited in the main text, in numerical order.
- Titles and legends sit in one "figures" section of the manuscript, never inside the image file.
- Main tables: Word table tool, black and white, one value per cell, no "Table 1A/1B", a title, footnotes with superscript lowercase letters.

## 5. Figures for production [FIG]

| Item | Rule |
|---|---|
| Widths (two-column formats: research articles) | **8.5 cm** (1 column), **11.4 cm** (1.5 columns), **17.4 cm** (full width) |
| Size | each figure fits one page; recommended maximum **16.5 × 20 cm** (6.5 × 8 in) so the legend can sit below |
| One file per figure | all panels in one file; file name like `Figure 1.tif`; legends not in the image |
| File size | **≤ 20 MB** each (LZW compression for TIFF; flatten layers) |
| File types | **TIFF and PDF preferred**; EPS, JPEG, PSD, PNG, CDX also accepted. AI files only for Leading Edge figures |
| Font | "use only **Arial** fonts"; always embed fonts |
| Text size | "about **6–8 pt** at the desired print size" |
| Panel labels | **capital letters** (no size or weight is specified) |
| Lines | stroke widths **0.5–1.5 pt** |
| Resolution at print size | colour or grayscale **≥ 300 dpi**; black and white **≥ 500 dpi**; line art **≥ 1,000 dpi** |
| Colour | **RGB**; "red and green should not be used together" |
| Gray fills | at least 20% different from each other; no lighter than 10%, no darker than 80% |
| Layers | flatten to one layer before saving |
| Spacing | "limit vertical space between parts of an illustration to only what is necessary" |
| In-figure references | avoid numbered reference citations inside artwork |
| Assembly | a vector program (Illustrator, Inkscape); Word and PowerPoint often reduce image resolution |

Image integrity [FIG]:

- Adjustments (contrast, brightness) apply to the whole image; exceptions explained in legend and methods.
- Gel lanes removed or rearranged: make it obvious (line or space) and say so in the legend. Full gels go in the supplement.
- Compare only data that belong together (same experiment).
- The same image in two figures only for the same experiment, with the reason in the legend.
- Never hide non-specific background.
- **Scale bar on every microscopy image.**
- Stitched images: say so in the legend.
- Original unprocessed data available on request; figures are screened for irregularities.
- Recommended: plot individual data points in addition to mean ± error.
- **Generative AI or AI-assisted tools may not create or alter research or data images**, including brightness, contrast or colour-balance adjustments.

## 6. Front-matter files [FINAL]

Highlights and eTOC blurb go together in one Word file, separate from the manuscript.

| Item | Rule |
|---|---|
| Highlights | up to **4** bullets; each **≤ 85 characters with spaces**; no abbreviations; core findings |
| eTOC blurb ("In brief") | **≤ 50 words, 2 sentences**; third person (no "we"); context and significance; for a general scientific audience |
| Graphical abstract | **required** for Cell |

Graphical abstract [GA]:

- One single-panel image; reads top to bottom or left to right, with a clear start and end.
- Distinct from any model figure in the paper; new findings only; **no data items of any type**.
- Shows the biological context (subcellular location, tissue or cell type, species).
- One process or one point; little text; simple labels; restrained colour; avoid red/green and red/black contrasts.
- **1200 × 1200 pixels at 300 dpi** (= 101.6 mm square); **Arial 8–12 pt**; TIFF, PDF or JPG.
- General-purpose generative AI tools **may not** be used to create it; dedicated scientific illustration tools (e.g. BioRender, with the right licence) are allowed.

## 7. Supplemental information [SI]

- No strict limit; **recommended ≤ 20 supplemental figures**. Combine related items; one supplemental figure may span pages.
- Titles name the main item they belong to: "Figure S1. [title], related to Figure 1".
- Naming: Figure S1, Table S1, Data S1, Methods S1, Video S1 (never "Supplementary Figure 1").
- Primary PDF ("Document S1"): A4/Letter, **≤ 50 MB**, **Arial 10 pt**; figures with legends, tables that fit ≤ 3 pages, notes, supplemental references; no title, authors or page numbers.
- **Methods never go in the supplement**: they belong in STAR Methods.
- Tables longer than 3 pages: Excel. Data and code: non-proprietary formats. No file above 500 MB.
- Supplemental references are numbered independently; references cited only in the supplement appear only there.
- The manuscript carries a "Supplemental information" index (Document S1 first).

## 8. STAR Methods [STAR, REVISE]

- Required at revision and for acceptance; not at first submission. Replaces "Experimental procedures"; part of the main article, not supplemental.
- Key resources table: Cell Press Word template or webform; RRIDs for antibodies and genetically modified organisms.
- Section headings (from the author guide, **not re-read on 2026-11-18**; confirm in the PDF): Key resources table · Experimental model and study participant details · Method details · Quantification and statistical analysis · Additional resources (optional).

## 9. References [REVISE]

- Numbered in order of first citation; in-text superscript numbers.
- "et al." only after **10** author names.
- Style: `Sondheimer, N., and Lindquist, S. (2000). Rnq1: an epigenetic modifier of protein function in yeast. Mol. Cell 5, 163–172. 10.1016/S1097-2765(00)80412-8.`
- Preprints allowed with a DOI ("Preprint at bioRxiv, …"); replace by the published version when it exists.
- Unpublished data, personal communications, abstracts: in text only, not in the list.
- Datasets, code and methods are cited and listed (DOI where one exists).

## 10. Where Cell differs from Nature (do not mix them up)

| Item | Cell | Nature (for contrast only) |
|---|---|---|
| Widths | 85 / 114 / 174 mm | 89 / 183 mm |
| Font | Arial only | Arial or Helvetica |
| Text size | about 6–8 pt | 5–7 pt |
| Panel labels | capital letters A, B, C | lowercase bold a, b, c |
| Abstract | "Summary", ≤ 150 words, plus Highlights, eTOC blurb, graphical abstract | summary paragraph, no highlights |
| Methods | STAR Methods with key resources table | Methods |
| Extra data figures | Figure S1…, "related to Figure N" | Extended Data Fig. 1–10 |
| Legends | title, then panels; statistics and n required; "See also Figure S1" | "Fig. 1 \| Title." |
| Citation | Author, A., and Author, B. (year). Title. Journal vol, pages. DOI | numbered Nature style |
