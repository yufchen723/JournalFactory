# In-text citations

## 1. Rules — Cell rule

| Rule | Where |
|---|---|
| References are numbered in order of first citation | cell.md §9 |
| In-text citations are superscript numbers | cell.md §9 |
| No citations in the Summary | cell.md §3 |
| Avoid numbered reference citations inside figure artwork | cell.md §5 |
| Unpublished data, personal communications and abstracts are cited in the text only, not in the list | cell.md §9 |
| Datasets, code and methods are cited and listed | cell.md §9 |
| Supplemental references are numbered independently; references cited only in the supplement appear only in the supplemental list | cell.md §7 |
| No footnotes outside the author list and tables | cell.md §3 |
| The reference list is the last component of the manuscript, after STAR Methods | cell.md §3 |
| References do not count toward the 7,000-word limit | cell.md §2 |

## 2. Not specified in cell.md — check cell.com

- Whether the superscript goes before or after punctuation.
- How ranges and lists are written (for example 1–3 versus 1,2,3; with or without spaces).
- How a named-author citation is written in running text ("Smith et al.⁵ showed" and when "et al." starts in the text).
- Whether citations in legends, tables and STAR Methods are numbered in the sequence of the main text at the place where the item sits in the manuscript file, or where it is first cited.
- How unpublished data and personal communications are worded in the text.
- Whether highlights and the eTOC blurb may contain citations (cell.md §6 lists no rule on it).

Use the defaults below until checked, and say they are defaults.

## 3. Working defaults — craft guidance (not a journal rule)

**Placement**

- Put the number at the claim it supports, not at the end of a long sentence that makes three claims.
- After a name: "Author et al.¹² showed that…".
- Keep one convention for position relative to punctuation throughout. Let the reference manager's Cell style decide; do not hand-edit.

**Numbering**

- Let the reference manager number. Hand numbering fails at the first inserted citation.
- Order of the manuscript components (cell.md §3) puts legends, tables and STAR Methods after the main text and before the references. A reference manager numbers by position in the file, so references first cited in STAR Methods get the highest numbers. That is consistent with "order of first citation" read through the file. Confirm if the editor objects.
- After every revision round, refresh the numbering and re-check any numbers typed by hand (in the response letter, in figure files).
- One number per reference. No "12a/12b". No reference listed twice under two numbers.

**How many citations per claim**

- One to three well-chosen references. A string of ten signals an unread list.
- Cite the original finding, not only a review. Use a review for background and say so ("reviewed in ¹⁴").
- Cite the method's original description and the software's own paper in STAR Methods.

**Datasets, code and software**

- Each reused dataset: cite its paper and, if the dataset has its own DOI, the dataset.
- Each tool: cite its paper; give the version in the key resources table.
- Own deposited code or data with a DOI: list and cite it (cell.md §9), and name it under Resource availability.

**Unpublished material**

- In text only (Cell rule). A common wording is "(A.B. Author, personal communication)" or "(data not shown)"; Cell's preferred wording, and whether "data not shown" is accepted, are not specified in cell.md.
- Get the named person's permission for a personal communication.
- If a claim matters, show the data in a supplemental figure instead.

**Supplemental information**

- Document S1 has its own reference list, numbered from 1 (Cell rule).
- A reference cited in both main text and supplement appears in both lists, each with its own number.
- A reference cited only in a supplemental legend must not be in the main list.

**Where citations must not appear**

- Summary (Cell rule).
- Inside figure artwork (Cell rule: avoid). Put the citation in the legend.
- Graphical abstract: carries little text and no data items (cell.md §6); do not put citations in it.

## 4. Claim-to-citation check — craft guidance

For each cited sentence, record:

| Sentence (short) | Ref | What the source shows (from the abstract or text, checked) | Support |
|---|---|---|---|
| "Factor X is induced under condition C" | 12 | Induction shown in cell type A in vitro | direct |
| "…and is required for process Z" | 12 | Not tested in that paper | **none: find another source or reword** |

Support grades: `direct` (the paper shows it), `partial` (shows part, or in another system: say so in the sentence), `background` (review), `none`.

## 5. Checklist

- [ ] Superscript numbers; numbered by first citation.
- [ ] No citations in the Summary or inside figure artwork.
- [ ] Every number in the text has an entry; every entry is cited.
- [ ] No hand-typed numbers left stale after renumbering.
- [ ] Unpublished items are in the text only.
- [ ] Datasets and code are cited and listed.
- [ ] Supplemental citations use the supplemental list.
- [ ] Each citation supports the specific claim it is attached to.
